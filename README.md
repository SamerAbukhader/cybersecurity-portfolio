# Cybersecurity Portfolio

My professional cybersecurity portfolio, built for WQE7001 Cyber Security. It presents my skills, hands-on projects, learning journey and career goals.

**Live site:** <https://samerabukhader.github.io/cybersecurity-portfolio/>

## Repository layout

| Path | Contents |
| --- | --- |
| `index.md` | Home page of the site, with all seven portfolio sections |
| `projects/virtual-lab-setup/` | Project 1: write-up and evidence |
| `projects/nmap-service-scan/` | Project 2: write-up and evidence |
| `assets/images/` | Images used by the site |
| `_config.yml` | Jekyll settings for GitHub Pages |

## Security and privacy

All evidence is sanitised before publishing: no credentials, public IP addresses, personal data or client information. All testing was done in my own lab or on legal practice platforms.
